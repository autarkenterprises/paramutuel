About Paramutuel

Parimutuel pools for propositions and events on Base: stake with a wallet, settle on-chain, claim from the pot — using classic enumerated outcomes, v2 ticket rules, or freeform text answers.

Protocol versions on-chain

Paramutuel ships multiple factory + wager pairs so creators can pick the right expressiveness. All versions share the same high-level lifecycle (betting window, resolution window, resolver authority, claim/refund rules) but differ in how positions are encoded.

  • v1 — Wagers with a fixed list of outcome labels; stakes reference a single winning index. Familiar single-winner parimutuel.
  • v2 — Same enumerated outcomes (up to 255), but tickets are bitmasks with configurable payoff policies (for example single-winner, any-of, exact-set, at-least-k, weighted overlap). Supports batch placeBets across multiple masks.
  • Freeform — No outcome list at create time. Bettors submit a UTF-8 answer string; the contract keys stakes by hash. The resolver must publish the exact winning string. Suited to open-ended predictions where enumerating every possibility up front is impractical.

Technical reference: docs/MACHINE.md and ADRs in research/adr/.

What you can do here

Use Propose a Wager for guided creation (templates and assisted flows in development), or Place a Bet to find wagers and stake with a wallet. The stake page routes to the right contract ABI: enumerated markets use placeBet / placeBets; freeform markets use placeBet(string,uint256) with your exact answer text. Direct links like bet.html?wager=0x… open the same flow. The Explorer lists wagers from the indexer; the full App bundles create, resolve, claim, and odds preview.

Testnet and mainnet

The strip under the navigation shows which network this deployment uses — for example Base Sepolia (testnet) for practice, or Base mainnet when the site is configured for production.

Testnet is real smart-contract behavior with tokens that have no monetary value; it stays useful for trying the flow even after mainnet is live. Mainnet involves real assets: always confirm the network in your wallet matches the banner before you sign anything.

Base Sepolia (common testnet): chain ID 84532, default public RPC endpoint https://sepolia.base.org.

Developers

The protocol, static site, and app are open source. Clone or browse the repo for Solidity contracts, the self-custody dApp, indexer, and tooling.

  • github.com/autarkenterprises/paramutuel

This public site focuses on participants. Technical documentation for running infrastructure lives in the repository for people who deploy their own environments.

Risks

Smart contracts and resolver choices can behave in ways you do not expect. Only use funds you can afford to lose, verify addresses (factory and wager) on a block explorer, and read each transaction in your wallet before approving.
