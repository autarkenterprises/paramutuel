Propose a Wager

Create a new on-chain parimutuel market: define the proposition, outcome labels, collateral token, betting and resolution windows, resolver (defaults to you), optional closers, and fee recipients. The factory deploys a dedicated ParamutuelWager contract.

Open app — create wager Browse existing markets

Use the same chain as the network strip under the navigation. The app fills the factory address from this site’s deployment config when available; you can override it if needed.

Developers / integrators: lifecycle and roles are documented in docs/WAGER-LIFECYCLE.md; ABI and HTTP surfaces in docs/MACHINE.md and About → Developers.
